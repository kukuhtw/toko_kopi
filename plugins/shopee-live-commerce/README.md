# Shopee Live Commerce Connector

Plugin MVP untuk menghubungkan Toko Kopi / AI Agent Commerce Platform dengan workflow Shopee Live.

## Fitur MVP

- Order webhook scaffold.
- Product mapping scaffold.
- Live analytics.
- Comment analyzer.
- AI live copilot.
- Voucher recommendation.
- Dashboard API.
- WhatsApp notification scaffold.

## Endpoint

```text
/plugins/shopee-live-commerce/webhook.php?branch=1
```

## Health Check

```text
/plugins/shopee-live-commerce/health.php
```

## Catatan Produksi

Production integration memerlukan Shopee Partner ID, Partner Key, Shop ID, Access Token, Refresh Token, dan approval Shopee Open Platform.
